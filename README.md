# CAD Assignment Repository

This repository contains submission files for a CAD assignment, including source drawing files, question sheets, and the final report.

## Repository Contents

- `2026 S1 CAD AT(1).pdf` – Assignment brief.
- `Question_1.pdf` to `Question_4.pdf` – Individual question documents.
- `22345563_Q1.dwg` to `22345563_Q4.dwg` – CAD drawing files for each question.
- `22345563_Report.pdf` – Final compiled report submission.
- `Yasiru_Fernando_2004.docx` – Supporting document.

## How to Open Files

- Use a CAD application (such as AutoCAD) to open `.dwg` files.
- Use any PDF viewer to read `.pdf` files.
- Use a word processor (such as Microsoft Word or LibreOffice Writer) to open `.docx` files.

## Notes

- This repository is primarily for submission/reference.
- No executable source code or build process is included.
